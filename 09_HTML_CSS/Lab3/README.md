# Lab3: CSS Fundamentals

## Overview
This lab is divided into two parts that explore CSS concepts:

- **Lab3.1**: Demonstrates various CSS selectors and their effects on HTML elements
- **Lab3.2**: Shows CSS specificity, precedence rules, and advanced styling techniques

## Structure
- `Lab3.1/`: CSS selectors demonstration
- `Lab3.2/`: CSS specificity and precedence

Each sub-lab contains HTML and CSS files that work together to illustrate key CSS concepts.

## Learning Objectives
- Understand different types of CSS selectors
- Learn about CSS specificity and how styles are applied
- Explore CSS precedence rules including `!important`
- Practice combining HTML structure with CSS styling

## Common Corner Cases Across Both Labs
- **Browser compatibility**: Ensure testing in multiple browsers
- **CSS validation**: Use validators to catch syntax errors
- **Responsive design**: Consider how styles work on different screen sizes
- **Accessibility**: Ensure color contrast and keyboard navigation
- **Performance**: Keep CSS efficient and avoid unnecessary complexity</content>
